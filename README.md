# Idioma IA

Professor particular de idiomas com IA, em aulas de 3 a 20 minutos, feito para celular.

- As telas do app ficam na raiz deste repositório e são publicadas pelo GitHub Pages.
- `servidor/Code.gs` é o servidor: cole numa planilha Google (Extensões > Apps Script), execute `instalar` e publique como App da Web.
- `config.js` guarda o endereço do servidor (o que termina em `/exec`).

A chave do Gemini fica só no servidor, em Propriedades do script (`GEMINI_API_KEY`). Ela não aparece neste repositório.
